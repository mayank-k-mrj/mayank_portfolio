GLTF / GLB 3D MODEL STORAGE DIRECTORY
=======================================

Place your 3D model files (.glb or .gltf) here.

Available / Configured Model Slots:
- /models/laptop.glb      -> Interactive 3D Laptop Model
- /models/workspace.glb   -> Interactive 3D Workstation Desk Model
- /models/trophy.glb      -> Interactive 3D Hackathon Trophy Model

The GLTFModelViewer component will automatically load and render any .glb 3D files placed in this folder with 360° OrbitControls, PBR lighting, and contact shadows!
